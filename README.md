# Junko Takahashi Portfolio Site

**業務理解 × AI活用 × システム化**

🔗 **公開サイト**: https://junko-takahashi-cloud.github.io/personal-site/

---

## このサイトについて

ここは自己紹介ページであると同時に、**実際にシステム制作のご相談を受け付けている「お店」**です。ページ内のお問い合わせフォームから、そのまま「こんなシステムを作ってほしい」というご相談・ご依頼を受け付けています。

20年以上、経理・学校事務・医局事務といった back-office 業務に携わってきました。日々の「この作業、手作業じゃなくて自動化できないか」という現場感覚を土台に、今はAIと協働しながらシステムを作るエンジニアとして活動しています。

## できること

- **業務理解**:経理・事務・現場運用を長年見てきた経験から、業務フローの「本当に困っている部分」を汲み取れます
- **AI活用**:ChatGPT・Claude・Gemini・Copilotなど複数のAIを役割分担させながら、要件定義から実装まで進める開発スタイルです
- **システム化**:Excel⇄CSV変換、請求書自動化、Web予約管理システムなど、実務に直結する自動化ツールを制作しています

## サイト構成

- **About** — 自己紹介・経歴
- **Skills** — 技術スキル
- **Works** — 制作実績(ボウリングレーン予約システム、Excel⇄CSV変換ツール、請求書PDF自動化など)
- **Devlog**(`devlog.html`) — 開発記録・ロードマップ。4AI協働での試行錯誤を記録しています
- **Contact** — お仕事のご相談フォーム(作ってほしいシステムの内容をヒアリングする形式)

## ご依頼・ご相談について

現在ココナラにて以下のサービスを出品しており、このサイトはその窓口も兼ねています。

- Python業務自動化③:小規模店舗向け・Web予約管理システム構築
- Python業務自動化②:Excelデータ→PDF請求書自動作成
- Python業務自動化①:Python業務自動化・CSV加工/データ整形
